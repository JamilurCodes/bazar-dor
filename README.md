# 🛒 বাজার দর — BazarDor

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর এক নজরে দেখার জন্য তৈরি একটি responsive ওয়েব অ্যাপ। পণ্যের দাম, দৈনিক ওঠানামা এবং বিভিন্ন বাজারের দামের তুলনা সহজভাবে দেখানোই এর উদ্দেশ্য।

## ✨ প্রধান বৈশিষ্ট্য

- বাংলা ভাষা, বাংলা সংখ্যা এবং বাংলাদেশি লোকেল অনুযায়ী তারিখ ও দাম প্রদর্শন
- পণ্যের দাম বৃদ্ধি ও হ্রাসের আলাদা বিভাগ
- ক্যাটাগরি অনুযায়ী পণ্য দেখা এবং দামের ভিত্তিতে সাজানো
- পণ্যের বিস্তারিত পৃষ্ঠা ও বাজারভিত্তিক দাম তুলনা
- Better Auth দিয়ে ইমেইল/পাসওয়ার্ড নিবন্ধন ও লগইন
- Google ও GitHub OAuth কনফিগার করার সুবিধা
- লগইন-সুরক্ষিত পণ্য বিস্তারিত এবং প্রোফাইল আপডেট
- responsive layout, loading skeleton, error/empty state ও toast notification
- অজানা URL-এর জন্য বন্ধুত্বপূর্ণ 404 পৃষ্ঠা

## 🧰 প্রযুক্তি

- Next.js App Router
- React ও TypeScript
- Tailwind CSS 4 + daisyUI (সেমান্টিক `btn`, `select`, `skeleton`-ধাঁচের UI components) এবং custom CSS design system
- Better Auth
- MongoDB
- `react-hot-toast`
- Bazar Dor assignment API
